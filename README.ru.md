# CongrArk

🌍 Языки: [EN](README.md) | [RU](README.ru.md) | [CZ](README.cs.md)

CongrArk — это оффлайн-приложение для работы с зашифрованными структурированными данными.

## Назначение

Приложение предназначено для работы с чувствительной информацией:

- отчёты
- записи и заметки
- списки и статистика
- административные данные

Главная идея: **данные никогда не сохраняются в открытом виде и не передаются на сервер.**

---

## Модель безопасности

CongrArk работает по принципу:

> данные существуют в расшифрованном виде только в памяти устройства

Особенности:

- AES-256-GCM шифрование
- пароль пользователя используется для генерации ключа
- нет сервера и облака
- нет аналитики и внешних запросов
- нет хранения открытых данных

---

## Как работает приложение

1. Открывается зашифрованный файл
2. Вводится пароль
3. Данные расшифровываются в память
4. Пользователь редактирует данные
5. Сохраняется новый зашифрованный файл

---

## Ограничения

CongrArk НЕ является:

- облачным сервисом
- системой синхронизации
- многопользовательской системой
- системой резервного копирования

Ответственность за хранение файлов лежит на пользователе.
