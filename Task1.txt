Создай MVP PWA-приложения на React + TypeScript + Vite.

Цель проекта — локальное хранение конфиденциальных данных без сервера и без базы данных. Все данные должны обрабатываться только в браузере пользователя.

Требования:

1. Архитектура

* React
* TypeScript
* Vite
* PWA (устанавливается как приложение на Windows, Android и других поддерживаемых платформах)
* Без бэкенда
* Без Firebase
* Без внешних API
* Вся логика работает локально в браузере

2. Шифрование
   Использовать Web Crypto API.

Алгоритм:

* AES-256-GCM для шифрования данных
* PBKDF2 для получения ключа из пароля
* Генерировать случайный salt
* Генерировать случайный IV
* Использовать не менее 100000 итераций PBKDF2

3. Формат файла

Приложение должно уметь работать с файлом:

secure-data.enc.json

Пример структуры:

{
"version": 1,
"salt": "...",
"iv": "...",
"data": "..."
}

В файле не должно быть открытых данных.

4. Первый запуск

Показывать экран:

* Создать новый файл
* Открыть существующий файл

5. Создание нового файла

Пользователь вводит пароль.

Создаётся объект:

{
"text": "Hello World"
}

После этого открывается редактор.

6. Открытие существующего файла

Пользователь:

* выбирает файл
* вводит пароль

Если пароль верный:

* данные расшифровываются
* открывается редактор

Если пароль неверный:

* показать понятную ошибку

7. Редактор

Для MVP достаточно:

* одного textarea
* данные хранятся в виде

{
"text": "..."
}

При изменении textarea обновляется состояние приложения.

8. Сохранение

Кнопка:

"Скачать зашифрованный файл"

При нажатии:

* данные сериализуются в JSON
* шифруются текущим паролем
* автоматически скачивается новый файл secure-data.enc.json

9. Смена пароля

Кнопка:

"Изменить пароль"

Пользователь вводит:

* текущий пароль
* новый пароль

После подтверждения:

* данные должны быть повторно зашифрованы новым паролем

10. Безопасность

После закрытия вкладки:

* данные не должны сохраняться в localStorage

Не использовать localStorage для хранения открытых данных.

Пароль не хранить нигде.

Не логировать пароль в консоль.

11. Дополнительно

Сделать аккуратный минималистичный интерфейс.

Код должен быть хорошо структурирован:

src/
crypto/
components/
hooks/
utils/
types/

Добавить комментарии только там, где действительно нужна логика шифрования.

В конце работы объясни:

* как запустить проект
* как собрать production-версию
* как установить как PWA
* как работает шифрование
* какие ограничения есть у такого решения


Не используй сторонние библиотеки для криптографии. Используй только встроенный Web Crypto API.
